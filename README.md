# Music Streaming Service

Java project for the Software Design Patterns final project.

## Patterns
- **Factory Method:** `TrackFactory`, `PopTrackFactory`, `RockTrackFactory`
- **Builder:** `PlaylistBuilder`, `Playlist`
- **Adapter:** `LegacyTrackAdapter`
- **Decorator:** `EchoDecorator`, `BassBoostDecorator`
- **Observer:** `MusicPlayer`, `NowPlayingDisplay`, `LyricsDisplay`
- **Strategy:** `SortContext`, `SortByTitle`, `SortByArtist`, `SortByDuration`

## Run
Open the project in IntelliJ IDEA and run `Main`.
